# PERSONA 光电链路工作台

PERSONA 用于离线编辑框图、机箱布局和器件参数，按实际连线计算 RF、光功率和直流预算。工程 JSON 独立保存。当前工程格式为版本 2，旧经验标定工程无法直接打开。

## 启动工作台

安装依赖后运行 `npm run dev`，打开 Vite 显示的地址。默认入口和 `/v1.html` 均进入当前工作台。工作台默认加载 V1 示例，也可新建空工程。

### 构建 V1 单 HTML

在干净的 V1 提交上执行以下命令。发布入口为 `v1.html`，用锁文件安装构建依赖。

```powershell
npm ci
npm run test:v1:model
npm run build:v1
Get-FileHash artifacts/v1/persona-v1.html -Algorithm SHA256
```

`artifacts/v1/` 包含 `persona-v1.html`、两份示例 JSON、第三方声明、`build-info.json` 和 `persona-v1.html.sha256`。构建信息记录源提交、工作树状态、最终 HTML 和示例文件的大小与 SHA256。HTML 内嵌运行资源及第三方声明，校验值以完成打包后的文件为准。

将 `persona-v1.html` 单独复制到空目录，停止开发服务器并断网，用 Windows Chrome 或 Edge 直接打开。页签标题应为「persona · V1 工作台」。可直接加载内置完整示例。若要打开外部工程，点击顶栏「打开工程 JSON」选择文件。

### 从空工程搭建框图

选中对象后，可在属性面板修改当前实例的名称、开关状态和可覆盖参数。这些设置按完整实例路径保存在工程 JSON 中。若参数由上级模块映射，点击「转到来源参数」可定位实际生效的设置。

点击或拖入库模板时，每次按当前模板创建独立的工程定义。按名称添加已有工程定义、复制或粘贴模块时也会独立复制每个内部对象。修改工程对象只影响其定义；修改库模板只影响后续创建。旧工程中原本共享的定义保持共享。高级库设置的显式更新仅适用于与库模板 ID 相同的旧工程快照。

选中一个模块后，「再次使用此模块」会在同一上级模块中新增一个使用共享结构的实例，初始采用定义中的默认设置。「复制为独立模块」会同时复制内部模块、器件定义、实例设置和内部布局。父层连线和工程命名链路仍指向原实例。编辑共享结构前，可展开右侧「当前编辑模块」查看共享结构受影响的位置。

机箱布局左侧列出待放置器件，点击或拖入即可摆放。右侧可设置实例的毫米坐标、长宽和旋转角度。数值按 Enter 或离开输入框时自动保存，角度选定后立即应用。长和宽均留空时使用定义参考尺寸，缺少参考尺寸时显示「尺寸未设置」。越界或重叠提示可点选定位。逻辑节点移动不影响毫米坐标。

框图中的模块可单独展开，在父层直接选中、拖动内部器件，并在同一层接线。模块的对外端口连接父层，框内端口用于连接到内部器件。选中器件或模块后，可在框图或右侧属性栏的「端口」区添加端口，共享定义会显示受影响的实例。模块新增的对外端口可稍后再接到内部。点击已有内部端口的名称，可引出同类型、同方向的对外端口。射频、光信号和控制端口可修改显示名称。供电端口按实例电压与方向自动显示，例如 `+5V IN` 或 `220V~ IN`，电压留空时显示 `?V`。模块对外端口有独立电压声明时显示该声明。未声明时沿内部映射显示当前实例的电压。组成模块或引出端口会保留这条映射，内部改压后外部标签随之更新。已有连接继续使用原端口 ID。框图和结构树中，单击选中对象，双击模块进入内部，展开按钮只展开或收起。使用面包屑返回上层。在画布右下角，点击「收起」「展开」或拖动滑块可批量调整模块展开深度，旁边显示当前深度和最大深度。右侧按钮用于缩放、定位选中对象和适应画布。顶栏「视图」可切换结构、器件库和属性栏，或进入全页展示。全页展示沿用右下角控件，点击「退出全页展示」可恢复进入前的视图。

点击顶栏「新建空工程」开始。点击顶栏的「新建模块」，在画布上选定位置，按 F2 改名。器件库的搜索框下方提供「新建器件」「新建模块」「新建机箱」，支持点击或拖入当前编辑模块。常用模板按光电、射频、电源与控制分类，用户模板和示例分别归组；搜索也会显示折叠分类中的匹配项。器件库也提供自定义名称添加和按尺寸新建空机箱。选中模块后，在右侧点击「添加内部对象」可进入该模块并打开器件库。端口可以拖线，也可以依次点击配对，绿色轮廓标出可连接的目标。连接、公开端口映射和 MPO 芯序表单位于右侧「当前编辑模块」，按画布的当前编辑范围应用。

从框图空白处按住左键拖动可框选，按 Ctrl 或 Shift 点选可增减选择。选中同一直接父模块下的多个对象后，拖动任一选中对象可整体移动，一次撤销即可恢复。也可在右侧点击「组成模块」并命名，系统会生成跨边界连线所需的对外端口，共享父模块的改动会应用到其复用位置。在框图空白处用右键或中键拖动可平移画布，也可按住空格用左键拖动。滚轮缩放，Esc 取消连线或选择。

展开的模块可以拖动标题栏移动，拖动四边或四角可调整框的大小。将单个器件或模块拖到同层模块的可见框内，出现「移入」和绿色边框后松手即可改变层级。也可从展开的模块拖到直接上一级，或在独立模块视图选中内部对象后点击「移到上一级」。两种操作均可一次撤销。在结构树中可把对象拖到同层模块或直接上一级的条目上，折叠模块也能接收。也可从对象属性选择「移到上一级」。共享定义的影响范围会在预览中列出。选中非根模块后，可在属性栏选择「解散模块（保留内部对象）」，确认前可查看上一级目标、提升对象及边界连接。Delete 仍用于删除选中对象及其内容。

选中对象后按 F2 打开属性栏并聚焦名称。按回车或离开输入框自动保存。选中器件、模块或单条连线后可按 Delete 删除。框选或用 Ctrl／Shift 多选对象后，按 Delete 一次删除整组，按 Ctrl+Z 一次恢复。按 Esc 取消正在进行的接线。用顶栏「保存工程 JSON」保存，再点「打开工程 JSON」重开。

### 从框图发起预算

点击光输出端口的名称可查看此处光功率，也可把射频或光端口设为链路起点、终点。选中机箱后可查看供电与功耗。结果在画布下方，可折叠、放大或关闭。点击结果明细中的端口名称会在框图定位。

试算输入默认留在当前会话。要在下次打开时恢复链路的频点、射频输入与供光条件，在链路面板点击「保存试算条件」，再保存工程 JSON。重开后，预算按当前工程与保存的输入重新计算。

光分路器（1×2）使用「输出 1 分光比」和「额外插损」计算两个光输出。连接两个不同目标后，分别选择对应链路可查看实际光功率。数字光模块（SFP）从数字发送输入经发送光输出传到对端接收光输入和数字接收输出。在链路设置中选择光通道，填写发射光功率、接收灵敏度及可选过载上限，即可查看收光功率和余量。光调制器（MZM）等有源模板默认带一个标称 5 V 的直流输入，可在属性栏调整、删除或添加供电端口。在高级设置的「直流负载」中选择实际负载端口并填写功耗。AC/DC 电源的交流输入默认标称 220 V RMS。在第一个直流输出的端口属性填写电压，也可用「＋ 添加端口」增加更多直流输出。每路可单独填写额定容量（W 或 A），预算按实际端口和所连负载计算。每次从库添加的电源可独立配置。DC/DC 的输出电压也可直接在端口填写。

旧工程或器件库使用 `dcSupply: { portId, capacity }` 时，导入会提示旧单路结构并保留原文件。若旧库保存在当前浏览器，可在「管理器件库」中选择「导出浏览器原始库 JSON」。转换时先保留备份，把器件的 `dcSupply` 改为 `true`，将原来的额定容量写入对应输出端口的 `supplyCapacity`（例如 `{"unit":"W","value":{"kind":"fixed","value":7}}`），在该端口的 `outputVoltageV` 填写实际固定电压。检查该器件的全部直流输出，每个都会独立供电。旧实例采用不同电压或容量时，应先拆分为独立定义。

从器件库拖入「直调激光器（DML）」时，把 RF 驱动接到射频输入，把光输出经实际光路接到 PD。平均输出光功率 P0（dBm）取自激光器光输出端口。加载 50 Ω 的直调系数 K（W/V）可填固定值或按频率编辑曲线。在「参数计算」选取 RF 端点和光通道，可查看 RF 增益、PD 输出和逐级光功率。缺少驱动功率时仍可查询相对增益。改变实际偏置后应检查 K 是否仍适用于新的工作点。

### V1 示例验收

顶栏「加载示例」打开[完整系统](examples/v1-project.json)。通过「打开工程 JSON」也可打开该文件或[独立发射机箱](examples/v1-tx-only.json)。

1. **跨机箱链路。** 在「计算 → 查看链路预算」选择「跨机箱电光—光电链路」。系统沿 DWDM_CH28 自动追溯到发射机箱 A 的激光器，经 MZM、光开关和 MPO 纤芯到达接收机箱 A 的 PD。
2. **核对正交小信号幅度估算。** 示例采用 2 GHz、0 dBm 激励、8.0103 dBm 光源、3 dB 最大透过插损、2 dB 开关损耗、5 V 半波电压及 0.8 A/W 响应度。PD 直接驱动外部 50 Ω 时，平均光功率为 0 dBm，平均光电流为 0.8 mA，输出约 −31.9952 dBm、5.61985 mVrms、15.8953 mVpp。将发射机箱 A 的光开关切换为「阻断」，预算显示路径断开。恢复「导通」后重新计算。
3. **纯射频与直流供电。** 选择「两级纯射频链路预算（pure-rf）」，输入 `−20 dBm`，总增益、输出和级联噪声系数 应为 **15.0 dB、−5.0 dBm、3.6 dB**。「计算 → 直流供电预算」中，`TX_A / dc-converter` 的 4 W 输出负载以效率 0.8 折算为 5 W 输入，加 3 W 直供负载，`TX_A / dc-supply` 总需求 **8.0 W**，额定 **7.0 W**，超载 **1.0 W**。在「发射机箱 A」的右侧属性栏中把「直供负载功耗」的实例覆盖设为 2 W，A 的需求变为 7.0 W，B 保持 8.0 W。
4. **布局与往返。** 在「机箱布局」选「发射机箱 A」和已放置的「调制器（MZM）」，把 X 从 20 改为 25 mm 并保存位置。通过顶栏按钮保存和重开下载的 JSON。调制器的 X 坐标 应仍为 25 mm，逻辑接线与坐标保留；复算使用器件参数及已保存的试算条件。
5. **独立发射端。** 打开 `v1-tx-only.json`，`tx-only` 显示尚未连接。在「计算 → 局部光功率」选「外部供光的电光路径」，选电光转换边界 `TX_A / mzm · RF_IN → OUT`、目标 `TX_A · OPT_OUT`、输出通道 `DWDM_CH28`。结果为 **0.0 dBm**。保存并重新打开后，`TEST_OUT` 仍开放，`tx-only` 仍只有起点。
